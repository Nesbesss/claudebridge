CLI Reference

Customize the bridge kernel behavior using the following command-line flags. Most flags can also be set via your .env file.

General & Auth

FlagDescription
--wizardLaunch interactive setup (recommended).
--api-key [k]Override or inject a specific API key.
--profile [p]Load a named persistent configuration profile.

Provider & Model

FlagDescription
--provider [id]Select primary node (openai, groq, ollama, etc).
--model [id]Manual model slug override.
--base-url [url]Point to a custom API node (e.g. self-hosted LM Studio).

Advanced Features

FlagDescription
--enable-routingActivate smart agentic re-routing.
--enable-cacheTurn on semantic response caching.
--verboseOutput full protocol telemetry to stdout.

Pro One-Liners

LOW COST DEV
claudebridge --provider groq --model llama-3-8b --enable-cache
LOCAL ONLY
claudebridge --provider ollama --model deepseek-coder --base-url http://localhost:11434
Help Command: Run claudebridge --help at any time for the full auto-generated flag manifest.
