The Doctor Tool

The --doctor command is your primary diagnostic suite for identifying and resolving bridge communication issues between Claude and your LLM providers.

Launch Diagnostics

Run the doctor from your terminal to begin a system-wide audit:

BASH
claudebridge --doctor

Audit Checklist

  • Environment Health: Verifies that ~/.claudebridge.env is present and has readable permissions.
  • Auth Verification: Pings each configured provider to ensure API keys haven't expired or been revoked.
  • Network Latency: Measures the round-trip time (RTT) for each node to identify bottlenecks.
  • MCP Linkage: Checks if Claude Desktop's config is correctly pointing to the active bridge process.

Common Health Results

IndicatorMeaning
PASSNode is healthy and responsive.
AUTH_ERRKey is invalid; run --wizard to re-authenticate.
TIMEOUTEndpoint is unreachable (check your connection or VPN).
Self-Healing: In many cases, the Doctor can automatically fix file permission errors or update stale MCP paths if you run it with elevated privileges.
