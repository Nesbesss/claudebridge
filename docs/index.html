Overview

ClaudeBridge is a high-performance proxy kernel that bridges Anthropic's Claude Code with elite LLM providers.

It acts as a protocol translator, intercepting the standard Anthropic signals and re-routing them to any of the 31 validated provider nodes. Whether you need the ultra-low latency of Groq, the reasoning power of DeepSeek-R1, or the local privacy of Ollama, ClaudeBridge provides a unified interface for all your agentic tasks.

Core Capabilities

  • Protocol Translation: Seamlessly converts Anthropic's message format to OpenAI, Mistral, and Ollama APIs.
  • Live Intercepts: Control your model and provider directly from the chat using $$ commands.
  • Agentic Routing: Automatically steer simple tasks to fast models and complex logic to reasoning-heavy models.
  • Semantic Caching: Reuse previous generations to save cost and achieve near-zero latency for similar queries.

Getting Started

New users should start with the Quickstart guide, which covers the 60-second installation and configuration flow using the interactive wizard.

Navigating the Docs

The documentation is split into four primary tracks:

  • Basics: Installation, authentication, and quickstart guides.
  • Core Concepts: Detailed guides on how intercepts, swapping, and profiles work.
  • Reference: Technical specifications for the CLI and internal protocol.
  • Advanced: Performance tuning, agentic routing, and the Doctor tool.
