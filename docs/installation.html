Installation

ClaudeBridge is a lightweight Node.js utility. To ensure stability and compatibility with the latest LLM provider protocol shifts, we recommend the following setup.

Prerequisites

  • Node.js: Version 18.0.0 or higher.
  • Package Manager: NPM (7+), Yarn, or PNPM.
  • Claude Desktop: (Recommended) If you plan to use ClaudeBridge as an MCP server.

Primary Installation

The fastest way to get started is via a global NPM installation. This makes the claudebridge command available system-wide.

NPM
npm install -g @nesbes/claudebridge
YARN
yarn global add @nesbes/claudebridge

Developer Installation

If you want to contribute or use the bleeding-edge version, clone the repository and link it locally.

BASH
git clone https://github.com/Nesbesss/claudebridge.git
cd claudebridge
npm install && npm link

Verification

Run the following command to verify that ClaudeBridge is correctly installed and visible in your PATH:

TERMINAL
claudebridge --version
Note: On macOS/Linux, you may need sudo depending on your NPM configuration, though we recommend using a version manager like nvm to avoid permission issues.
