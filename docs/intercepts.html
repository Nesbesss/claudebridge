Live Intercepts ($$)

One of ClaudeBridge's most powerful features is the ability to send commands to the bridge kernel directly from your chat window (Claude Desktop or CLI). These commands start with $$ and are intercepted by the bridge server. They are never sent to the LLM provider and do not pollute your context window.

Session & Dashboard

CommandResult
$$statusFull dashboard with active model, provider, and performance stats.
$$costDetailed spend report for the current session and all-time.
$$speedReal-time telemetry: tokens/sec, TTFT, and total latency.
$$infoAlias for status.

Model & Provider Switching

Instantly swap your underlying "intelligence" without restarting the bridge.

CommandEffect
$$groqSwitch to Groq (Llama 3 / Mixtral) using preset optimized config.
$$ollamaSwitch to local Ollama node.
$$model:[id]Switch only the model ID (e.g., $$model:gpt-4o).
$$resetRevert to default configuration from your .env file.

Feature Control

Toggle advanced kernel features on the fly.

CommandEffect
$$routing [on/off]Enable/Disable smart agentic routing logic.
$$cache clearFlush the semantic cache to force fresh generations.
$$fallback onEnable cross-provider fallback chains for high reliability.
Tip: You can combine a command with a prompt! For example, $$groq What time is it? will perform the switch AND send the query in a single round-trip.
