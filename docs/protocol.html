Protocol Specification

ClaudeBridge operates as a high-fidelity protocol shim. It intercepts outgoing requests from the claude client (Anthropic format) and translates them into provider-specific payloads (OpenAI, Mistral, etc.) in real-time.

Message Transformation

The kernel performs a recursive transformation of the message tree. Roles are mapped to their nearest semantic equivalents to maintain consistent agentic behavior.

Anthropic RoleOpenAI Equivalent
Useruser
Assistantassistant
Systemsystem (or developer)

The Proxy Kernel

When you launch a session, ClaudeBridge initializes an internal HTTP server on localhost:8787. It then updates your shell environment to point the ANTHROPIC_BASE_URL to this local node.

Streaming & Tool Calls

  • SSE Translation: Translates Anthropic's message_start and content_block_delta events into OpenAI choice.delta streams.
  • Tool Mapping: Complex tool definitions (JSON Schema) are normalized to function-calling specifications for the destination provider.
  • Intercept Layer: Scans the first 4096 bytes of every user message for $$ commands prior to transmission.
Performance: The transformation logic is implemented in native JavaScript with zero external network dependencies, ensuring sub-millisecond overhead.
