Quickstart

Bridge any upstream model to your Claude Desktop or CLI in under 60 seconds. Follow this three-step pipeline to get started.

1. Install

Pull the latest stable build from the central NPM registry.

TERMINAL
npm install -g @nesbes/claudebridge

2. Configure

Launch the interactive wizard. It will ask for your provider of choice and your API key.

BASH
claudebridge --wizard

3. Launch Claude

Once the wizard completes, it will automatically update your MCP configuration. Simply restart Claude Desktop or run your first command in the Claude CLI.

CLAUDE CLI
claude "Who is the master of puppets?"

Verification

In your Claude session, type $$status to verify that the bridge is active and correctly routing traffic to your chosen provider.

Pro Tip: Use the --doctor command if you experience any connection hiccups during the first run.
