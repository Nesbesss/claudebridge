Model Swapping

ClaudeBridge is unique in its ability to hot-swap the underlying LLM "brain" without terminating your active Claude session. This allows you to use different models for different phases of a coding task.

In-Session Swapping

To change the active model ID, use the $$model intercept command. This is useful when you want to stay within the same provider but switch to a larger or smaller variant.

INTERCEPT
$$model:gpt-4o
$$model:gpt-4o-mini

Full Provider Swapping

You can also jump between entirely different infrastructure providers (e.g., moving from a local Ollama node to a cloud-hosted Groq node) using provider-specific shorthand.

INTERCEPT
$$groq
$$ollama
$$openai

Strategic Use Cases

  • The Draft Shift: Use a fast, cheap model (like Llama 3 8B via Groq) to write boilerplate, then swap to GPT-4o for complex logic verification.
  • Local Privacy: Swap to $$ollama when working with sensitive internal data that must not leave your machine.
  • Rate-Limit Evasion: If you hit a tier limit on one provider, instantly pivot to another without losing your chat context.
State Persistence: When you swap models, ClaudeBridge maintains your current session's message history and context, re-transmitting it to the new provider so the assistant never "forgets" what you were working on.
