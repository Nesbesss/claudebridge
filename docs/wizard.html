Interactive Wizard

Configuring complex LLM providers and bridging them to Claude Code shouldn't require a degree in infrastructure. The ClaudeBridge --wizard is an interactive utility designed to get you from zero to agentic in under 60 seconds.

Getting Started

To launch the interactive setup, simply run:

EXECUTE
claudebridge --wizard

Step-by-Step Flow

The wizard will guide you through the following sequence:

  • Provider Selection: Choose from a curated list of providers (OpenAI, Groq, Mistral, locally-hosted Ollama, etc.).
  • API Key Validation: Securely input your keys. The wizard performs a real-time "ping" test to ensure they are valid.
  • Model Selection: Pick the specific model variant (e.g., Llama 3 70B, GPT-4o) that you want to bridge.
  • MCP Configuration: Automatically detect and update your claude_desktop_config.json to link the bridge.

Automated Side Effects

When the wizard completes, it performs several behind-the-scenes actions:

  • Creates/Updates ~/.claudebridge.env with your configuration.
  • Generates a persistence profile for your active model choice.
  • Restarts the local shim server to apply new routing rules.
  • Synchronizes with Claude Desktop settings if requested.
Security Note: Your API keys are stored locally on your machine in your home directory. ClaudeBridge never transmits these keys to any third-party server other than the direct API endpoint of the provider you selected.
