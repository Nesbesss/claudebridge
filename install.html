The Setup Wizard.

Launch the interactive bridge configurator by running npx claudebridge --wizard. Follow the 5-step kernel initialization sequence below to link your preferred provider.

01

Select Provider

Choose from 28+ validated nodes including local (Ollama) and cloud (Groq). Type the number corresponding to your node.

› Provider number (default: 1): 6

⌨ TIP: Simply press Enter to select node 01 (Claude.ai Web).

02

Authentication

Paste your API key. For specialized nodes, follow these prompts:

GITHUB COPILOT

A browser window will open. Paste the 8-digit device code shown in your terminal.

CLAUDE WEB SESSION

Paste your claude.ai browser cookie string to access free-tier reasoning nodes.

03

Model Discovery

The bridge will pulse your provider's /v1/models endpoint and list all available IDs. Type the number of the model you wish to use as your session primary.

✔ Found 12 models available
› Model (# / n / p): 3
04

Bridge Init

Finalize your local port (default 8787). The wizard will then perform a global system configuration.

AUTO-CONFIGURED FILES:

• ~/.claudebridge.env (Global Config)

• ~/.claude/settings.json (Claude Code Integration)
